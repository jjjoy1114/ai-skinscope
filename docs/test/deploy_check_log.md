## 발견한 문제

- 추천 성분 설명 일부가 영어로 표시됨(펩타이드, 바쿠치올) — 결과 화면 추천 성분 영역
- AI 스킨케어 팁 문장 오타: "유수분 밸런스를 유전하세요"(→ 유지하세요) — 공유 결과 화면
- (개선) 이미지가 아닌 파일 오류가 브라우저 알림창으로 뜨고 "text/markdown" 같은 기술 용어가 그대로 보임 → 화면 안 안내와 쉬운 문구(예: "사진 파일(JPG, PNG)만 올릴 수 있어요")로 개선 필요, 파일 선택 창에서 사진만 고르도록 제한하는 것도 검토 — 업로드 화면
- 분석에 실패한 시도(얼굴 없는 사진, 이미지가 아닌 파일)가 0점 기록으로 이력에 저장됨(SCAN 005~007) → 변화 추이·점수 비교에 0점이 섞일 수 있음. 실제로 변화 추이 항목 증감이 모두 하락(붉은기 -14, 수분 -7 등)으로 표시됨. 1차 테스트 기록에도 0점 4건 존재 — 이력 화면

## 참고 관찰 (문제 아님)

- 분석 소요 시간: 첫 요청 49초(무료 Render 서버 대기), 이후 약 18초 → NFR-01(10초 이내) 기준 미충족. AI 분석 호출 시간과 무료 서버 성능의 한계로 보이며 결과 보고서 7절(한계)에 기록

- 동일 인물 사진 비교: 만 39세 사진 68점(피부 나이 36세) / 만 30세 때 사진 83점 → 젊을 때 사진이 더 높게 나와 나이에 따른 피부 변화를 합리적으로 반영함
- 같은 사진 반복 분석 시 종합 점수 76~83점 범위로 변동(AI 판정 특성상 소폭 변동 발생, 결과 보고서에 한계로 기록)
- 동년배 비교 문구에 "탄력이(가)"처럼 조사가 기계적으로 붙음(사소한 문장 다듬기 거리)
- 챗봇 추천 질문이 결과와 맞지 않을 때가 있음(모공 80점 "매우 양호"인데 "모공 점수가 낮은데…" 추천) — 추천 질문이 고정 문구로 보임
