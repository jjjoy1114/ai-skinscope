## 1. 테스트 개요

| 항목 | 내용 |
| --- | --- |
| 기간 | 2026-08-25 ~ 2026-08-31 (사전 구성 팀의 프로토타입 테스트) |
| 대상(타깃) | 피부 상태를 스스로 확인·관리하고 싶은 일반인 — 기획서 대상 사용자 "일반 대중", 페르소나 20세 대학생·26세 직장인·32세 직장인 ([`Service기획서.md`](../Service기획서.md)) |
| 모집 방법 | 팀원의 지인 중 20~40대 일반인에게 프로토타입 링크를 전달해 모집. 코디세이 교육생(다른 팀 포함)은 포함하지 않음 |
| 타깃 해당 근거 | 피부 관리에 관심 있는 20~40대 일반인으로, 기획서의 대상(일반 대중)과 페르소나 연령대(20~32세)를 포함함. 의료·피부 전문가나 개발 관계자가 아닌 실제 사용자 관점 |
| 방법 | 테스터가 본인 휴대폰으로 프로토타입에 접속 → 촬영 동의 후 본인 얼굴 사진으로 분석 → 결과 화면 하단 피드백 카드에 응답 |
| 제외 | 팀원 테스트 기록 23건 제외 (`scripts/anonymize_test_results.py`, PR #37) |
| 결과 | 참여자 **40명**, 분석 **154건**, 피드백 참여 13명, 만족도 평균 **4.3 / 5** (15건), 서술형 의견 10건 |
| 개인정보 | 이름·연락처는 수집·기록하지 않음. 앱의 무작위 익명 ID를 가명(T1~T40)으로 바꿔 표기. 사진은 저장하지 않음 |
