# AI Hub 데이터 분석 및 추출 보고서

정리·검증: 오주연 · 원본 추출 실행: 서경환(원본 데이터 보유) · 작성 시점: 2026-10 (턴 3)

AI-SkinScope의 채점 기준, RAG 근거, 성분 추천은 모두 AI Hub 개방 데이터에서 추출한 참고 데이터에 기대고 있습니다. 이 문서는 어떤 데이터셋에서 무엇을 어떻게 뽑았는지, 결과가 서비스의 어디에 쓰이는지를 정리합니다.

## 1. 원칙

- AI Hub 원본(사진, CSV, 라벨 파일)은 **재배포 금지**이므로 저장소에 올리지 않습니다. 원본은 개발자 로컬(`D:\AI_DB`)에만 있습니다.
- 저장소에는 **추출 스크립트**(`scripts/build_*.py`)와 **추출 결과물**(`app/data/*.json`)만 둡니다. 결과물은 통계값, 임베딩 숫자 벡터, 성분 순위로, 원본 이미지나 개인을 복원할 수 없습니다.
- "피부 질환 진단 의료 이미지" 데이터셋은 오프라인 안심존 전용이라 사용하지 않았습니다.

임베딩은 모두 `gemini-embedding-2`(768차원)로 만들었고, 검색은 코사인 유사도 상위 5건을 씁니다.

## 4. 한국인 피부상태 측정 데이터 분석

### 4-1. 지표 정의

`meta_data.csv`와 `measurement_data.csv`를 피험자 번호(`subject_no`)로 조인한 뒤, 원본 컬럼을 5개 지표로 묶었습니다. 한 지표에 컬럼이 여럿이면 평균을 씁니다.

| 지표 | 원본 컬럼 |
| --- | --- |
| 수분(moisture) | 수분_이마, 수분_오른쪽볼, 수분_왼쪽볼, 수분_턱 |
| 탄력(elasticity) | 탄력_이마_Q0, 탄력_오른쪽볼_Q0, 탄력_왼쪽볼_Q0, 탄력_턱_Q0 |
| 주름(wrinkle) | 주름_왼쪽눈가_Ra, 주름_오른쪽눈가_Ra |
| 색소침착(pigmentation) | 스팟개수_정면 |
| 모공(pore) | 모공개수_오른쪽볼, 모공개수_왼쪽볼 |

붉은기는 대응하는 장비 실측 컬럼이 없어 기준 데이터 없이 AI의 시각 판단으로만 평가합니다.

### 4-2. 전체 1,072명 백분위

| 지표 | p5 | p25 | p50 | p75 | p95 |
| --- | --- | --- | --- | --- | --- |
| 수분 | 46.08 | 55.66 | 61.79 | 68.33 | 76.42 |
| 탄력 | 35.76 | 42.59 | 48.57 | 55.66 | 66.10 |
| 주름(Ra) | 14.21 | 17.73 | 21.14 | 24.98 | 31.68 |
| 색소침착(스팟 개수) | 57.00 | 111.75 | 157.00 | 207.00 | 266.45 |
| 모공(개수) | 234.28 | 551.50 | 872.50 | 1206.00 | 1710.40 |

수분·탄력은 높을수록, 주름·색소침착·모공은 낮을수록 좋은 값입니다.

### 4-3. 연령대별 인원과 중앙값(p50)

| 연령대 | 인원 | 수분 | 탄력 | 주름 | 색소침착 | 모공 |
| --- | --- | --- | --- | --- | --- | --- |
| 10대 | 106 | 57.29 | 58.57 | 17.34 | 82.0 | 351.5 |
| 20대 | 195 | 62.50 | 52.55 | 18.60 | 110.0 | 835.0 |
| 30대 | 195 | 60.67 | 47.90 | 20.98 | 140.0 | 913.5 |
| 40대 | 196 | 62.17 | 47.85 | 22.40 | 179.0 | 981.0 |
| 50대 | 194 | 62.67 | 44.65 | 23.31 | 195.5 | 985.75 |
| 60대 | 186 | 62.92 | 45.48 | 24.33 | 201.5 | 933.75 |

읽히는 경향: 탄력은 10대에서 50대까지 꾸준히 낮아지고, 주름과 색소침착은 나이와 함께 늘어납니다. 수분은 연령대 간 차이가 작습니다. 이 차이 때문에 전체 인구 기준 하나로 채점하면 나이에 따라 불리·유리가 생기므로, 나이를 입력한 사용자는 같은 연령대(가능하면 같은 성별) 그룹을 기준으로 비교합니다.

연령대×성별 12개 그룹은 51~99명으로 모두 최소 인원 기준(15명)을 넘습니다.

### 4-4. 부위별 기준

이마·왼볼·오른볼·턱은 수분과 탄력 실측 컬럼을, 양볼은 모공 개수 컬럼도 그대로 써서 부위별 백분위를 계산했습니다. 코에 대응하는 장비 실측값은 이 데이터셋에 없어(60명 표본의 스마트폰 라벨에서 해당 슬롯이 모두 비어 있음을 확인) 코 부위는 기준 데이터 없이 시각 판단으로 평가합니다.

### 4-5. 사진-실측값 인덱스 (RAG ②)

Training·Validation의 스마트폰 정면 사진 300명분을 임베딩하고, 각 인물의 라벨 7개(부위 0~6)에서 실측 집계값(수분, 탄력, 주름 Ra, 모공 개수, 색소침착 개수)을 붙여 저장했습니다. 사용자 사진과 가장 닮은 5명의 실측값이 채점 프롬프트에 근거로 들어갑니다. 실제 인물의 얼굴 사진이므로 원본은 저장소에 올리지 않고 임베딩과 집계값만 남깁니다.

## 5. 안면부 피부질환 이미지 합성데이터 분석 (RAG ①)

건선, 아토피피부염, 여드름, 지루피부염, 주사 5종에 대해 근접 촬영 폴더에서 질환당 100장씩 500장을 임베딩했습니다. 사용자 사진과 유사한 상위 5장의 질환 분포를 "유사 증상 패턴" 안내의 근거로 씁니다. 합성 이미지 기반이고 표본이 질환당 100장이므로, 결과는 진단이 아닌 참고 정보로만 표시합니다.

## 6. 스킨케어 성분-효능 추천 데이터 분석

### 6-1. 방법

Training(압축 해제된 jsonl)과 Validation(zip 안의 jsonl을 풀지 않고 직접 읽음) 라벨 9,000건을 표본 추출 없이 전부 읽었습니다. 각 레코드의 답변·추론 텍스트에서 "INCI명(한글명)" 형태로 등장하는 성분을 정규식으로 뽑아 고민 카테고리별 등장 횟수를 세고, `지식성분데이터.xlsx`의 효능 설명과 권장 피부 타입을 붙였습니다.

| 고민 | 레코드 수 | 비고 |
| --- | --- | --- |
| 미백(색소침착·기미·칙칙함) | 3,223 |  |
| 모공 | 2,891 |  |

### 6-3. 빈도 대신 특이도를 쓴 이유

단순 등장 빈도로 순위를 매기면 상위 성분이 모든 고민에서 비슷하게 겹쳐 추천이 차별화되지 않았습니다. 그래서 다음 값을 계산해 순위 기준으로 삼았습니다.

```text
특이도 = (해당 고민에서의 언급 비율) ÷ (전체 9,000건에서의 언급 비율)
```

1.0이면 어느 고민에서나 비슷하게 나오는 성분이고, 값이 클수록 그 고민에 특화된 성분입니다. 언급이 3건 미만인 성분은 값이 과하게 튀므로 제외했습니다.

| 고민 | 특이도 상위 성분 (특이도) |
| --- | --- |
| 모공 | 밤부사 불가리스잎/줄기추출물 (2.07), 밤부사 불가리스잎추출물 (1.72), 바쿠치올 (1.43) |
| 여드름 | 안디로바씨오일 (2.50), 아디픽애씨드/다이글라이콜크로스폴리머 (1.67), 우엉뿌리추출물 (1.62) |
| 주름 | 고추냉이 뿌리 추출물 (3.00), 아세틸헥사펩타이드-8 (1.82), 비에이치에이 (1.41) |
| 색소침착 | 펩타이드 (1.46), 키위수 (1.43), 바쿠치올 (1.43) |
| 붉어짐 | 헥사펩타이드-3 (2.16), 소듐티오설페이트 (1.96), 헥사펩타이드-11 (1.76) |

### 6-4. 한계

- 카테고리별 레코드 수 편차가 큽니다(3,223건 대 7건). 탄력·건조·민감성은 표본이 적어 순위가 불안정합니다.
- 특이도 상위 일부 성분은 실제 언급이 3~4건 수준입니다. 최소 언급 기준을 높이는 것이 개선 과제입니다.
- 성분 추출은 정규식 기반이라 표기가 다른 같은 성분이 따로 집계될 수 있습니다(예: 밤부사 불가리스잎추출물 2종).

## 7. 챗봇 지식베이스 (RAG ③)

6장의 성분 순위에서 고유 성분 41종의 효능 설명을 문서로 만들고, 직접 작성한 스킨케어 FAQ 26개(`skincare_faq.json`)를 더해 67개 문서를 임베딩했습니다. 챗봇은 질문과 유사한 문서를 검색해 그 내용을 근거로 답합니다.

## 8. 다시 추출하는 방법

원본이 `D:\AI_DB`에 있고 가상환경이 활성화된 상태에서 실행합니다.

```bash
python scripts/build_age_gender_reference.py
python scripts/build_region_reference.py
python scripts/build_ingredient_map.py
python scripts/build_reference_embeddings.py
python scripts/build_measurement_reference.py
python scripts/build_knowledge_base.py
```

위 3개는 CSV·라벨 통계라 API 키 없이 실행됩니다. 아래 3개는 `.env`의 `GEMINI_API_KEY`가 필요하고 임베딩을 약 870회 호출합니다. 팀 저장소로 옮길 때 원본을 보유한 서경환이 통계 3종을 다시 추출했고, 오주연이 그 출력을 이 보고서의 수치와 대조해 프로토타입 결과와 같은지 확인했습니다. 임베딩 3종은 2026년 8월 프로토타입 단계에서 추출한 결과를 그대로 사용했습니다.
